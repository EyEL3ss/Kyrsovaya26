Курсовой проект, залитый на отдельный репозиторий 


Курсовой проект нацелен на работу с скидочными картами, их добавление, сканирование и просмотр данных карт

Основные возможности

1) Просмотр скидочных карт с подробной информацией
2) Ручное добавление карт
3) Добавление часто используемых карт в избранное
4) Сканирование штрихкода существующей карты


Руководство запуска приложения

1) Установить приложение на мобильное устройство
2) Запустить приложение с ярлыка
3) Пройти регистрацию либо войти в аккаунт
